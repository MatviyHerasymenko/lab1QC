Radiobutton

Призначення: Дозволяє користувачу вибрати лише один взаємовиключний варіант із заздалегідь визначеного списку опцій. Вибір будь-якого нового перемикача автоматично знімає відмітку з попереднього у межах однієї групи (атрибут name).

Checkbox

Призначення: Дозволяє користувачу обрати декілька варіантів одночасно (або жодного), а також увімкнути чи вимкнути окрему незалежну бінарну опцію (наприклад, погодження з правилами сайту).
Інтерактивний приклад:
3

Text Input

Призначення: Забезпечує введення довільних текстових даних користувачем: імені, логіна, адреси електронної пошти, пароля чи пошукового запиту.
Інтерактивний приклад:
4

Tabs

Призначення: Організовують та логічно структурують вміст сторінки за категоріями в межах однієї секції, дозволяючи користувачеві перемикатися між ними без перезавантаження всієї сторінки.
Інтерактивний приклад:
Налаштування публічної інформації користувача, зміна фотографії та контактних даних.
Керування безпекою: зміна паролю, активні сесії та налаштування двофакторної автентифікації (2FA).
Історія фінансових транзакцій, виставлені інвойси та керування прив'язаними картами.
5

Button

Призначення: Слугує для ініціації певної дії користувачем: відправки форми, збереження налаштувань, відкриття чи закриття вікон, підтвердження або скасування операції.
Інтерактивний приклад (натисніть будь-яку кнопку):
Статус дії: Натисніть на кнопку вище для перевірки
6

Text Label

Призначення: Забезпечує текстовий підпис до інших елементів управління (покращуючи юзабіліті та доступність через <label for="...">) або відображає стислий стан системи у вигляді тегів і бейджів.
Інтерактивний приклад:
● Активний ⏳ В очікуванні ℹ Новий реліз
7

Link

Призначення: Навігаційний компонент, який забезпечує перехід на іншу сторінку, відкриття зовнішнього веб-ресурсу, завантаження файлу або плавний скрол до потрібного блоку на поточній сторінці (якірні лінки).
Інтерактивний приклад:
Перейти на GitHub ↗ Повернутися нагору ↑ Документація MDN Web Docs ↗
8

Tooltip

Призначення: Відображає коротку контекстну довідку чи пояснення при наведенні курсора миші (hover) або фокусуванні на елементі, заощаджуючи простір основного інтерфейсу.
Інтерактивний приклад (наведіть курсор):
Наведіть на мене курсор 🔍 Це спливаюча підказка (Tooltip), яка містить роз'яснення чи підказку до інтерфейсу!
9

Dropdown List

Призначення: Компактно відображає великий перелік варіантів вибору у згорнутому вигляді. При кліку розгортає меню вибору одного або декількох пунктів.
Інтерактивний приклад:
10

Data Grid

Призначення: Забезпечує структуроване представлення даних у вигляді рядків і колонок. У повноцінних інтерфейсах Data Grid також підтримує сортування, пагінацію та фільтрацію великих масивів інформації.
